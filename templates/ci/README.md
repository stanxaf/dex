# Application CI starter

`node-starter.yml` is a copyable GitHub Actions starting point for a Node project with `package-lock.json` and **required** `lint`, `typecheck`, `test`, and `build` npm scripts. Copy it to the application's `.github/workflows/`, pin action revisions according to your organization, adapt the supported Node version and scripts, and make all required jobs branch-protection checks. A missing script fails; a green result is not evidence for checks the workflow does not run.

For each applicable gate add an actual project-owned command or job for integration, e2e, accessibility, visual regression, dependency scanning, secret scanning and migration validation. Make the job fail if a required tool or script is missing; configure secrets and least-privilege permissions securely, avoid production data and do not expose credentials to untrusted pull requests. Set required status checks after creating jobs. Document unavailable checks and block merge where they are required; don't mark optional examples as completed checks. This starter does not implement scanning, accessibility or migrations by itself. Non-Node projects should translate the job to their real commands rather than install Node solely for this template.
