# Baseline

Apply the workflow, engineering, security, agent-operations, design (when UI exists), and quality-gate standards. Record the permitted agent tools, approval mode, readable data classes and instruction reading tiers in the project configuration; keep the instruction set reconciled per instruction hygiene. Configure proportionate checks and document commands and responsible owner. Review actual changes and evidence before merge; ask for human approval for the listed high-impact operations. For small tasks a brief plan and targeted check are enough if risk is low. Identify exceptions and failure evidence in the task or PR.
