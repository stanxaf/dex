# Baseline

Apply the workflow, engineering, security, agent-operations, deployment-gate (before automated deployment), design (when UI exists), and quality-gate standards, and keep the instruction set reconciled per instruction hygiene. Record in the project configuration the permitted agent tools, approval mode and sandbox posture, egress, readable data classes and reading tiers, together with proportionate checks, their exact commands and an owner. This profile adds no approval beyond the workflow's boundaries; the web-saas and regulated profiles do.
