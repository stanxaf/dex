# Web SaaS: baseline plus

Document authentication, authorization, tenant boundaries (if applicable), API contracts, data flows, deployment and recovery. Test access denial and tenant isolation at server/data boundaries, invalid inputs and critical API behavior. For migrations validate realistic data, rollout compatibility and recovery. Define required accessibility checks and critical user journeys, and test rendered UI across relevant viewports. Configure dependency and secret scanning and deployment permissions. Production deployment and auth changes require the workflow's explicit approval; an automated one must also meet AGT-15 to AGT-21.
