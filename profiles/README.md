# Profiles

Read [baseline](baseline/PROFILE.md) for all projects. Add [web-saas](web-saas/PROFILE.md) for networked SaaS; add both web-saas and [regulated](regulated/PROFILE.md) for high-integrity or regulated systems. Select the highest applicable profile in `.ai-governance.md`; project requirements may tighten it. A profile names policy, not a certification or automatic tool configuration.
