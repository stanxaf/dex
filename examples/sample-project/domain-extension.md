# Example project domain extension

Profile: regulated. Domain owner: project payroll lead (assigned by project). Each calculation rule needs a version, effective date, authoritative source, approval, rounding convention, and independently reviewed test fixtures. Preserve inputs and outputs in access-controlled audit records and reconcile historical results after corrections. Never derive statutory figures from this example. Use synthetic test data. Rule changes require domain-owner approval and independent human verification before release.

Illustrative fixture: Given an approved **fictional** rule `bonus-v1` of `2 × input`, input `5` produces `10`. This only demonstrates traceability; it is not a payroll formula. A real fixture must link its authoritative rule, effective date and independent reviewer.
