# Planning

Input: the request, acceptance criteria, project instructions and `.ai-governance.md`. Read the selected profile, `.ai-foundation/docs/agent-governance/workflow.md`, and relevant architecture and design sources. Inspect existing modules, components and tests before proposing changes.

Identify scope and non-goals, affected interfaces/data, states and edge cases, dependencies, risks, approvals, recovery and proportionate checks. Flag unresolved contradictions or consequential product decisions and obtain an authorized decision before dependent work. Output the workflow's concise implementation brief, applying its coder-selection and handoff rules when a target is named. Complete when the plan is bounded, sources and uncertainties are explicit, and required approvals are identified; do not claim implementation or tests occurred.
