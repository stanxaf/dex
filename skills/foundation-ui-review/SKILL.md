# UI and UX review

Input: request, actual UI and diff, `.ai-governance.md`, design sources and visual baselines. Read `.ai-foundation/docs/design/design-system.md` and selected profile. Inspect approved components, tokens and typography. Test representative viewports and keyboard/focus behavior; inspect loading, empty, success, error, validation and disabled states as applicable. Compare screenshots or visual regression evidence when available.

Report actionable findings with location, viewport/state, reproduction and impact; record unavailable rendered inspection and any missing checks. Escalate consequential design-system extensions and unresolved product choices to the owner. Complete when relevant states and evidence were inspected or limitations are explicit; do not approve a visual change from code alone.
